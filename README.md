# Lógica de Programação

Projetos e atividades da disciplina **Lógica de Programação (LPR014701)** do curso Técnico em Informática para Internet — IFSC.

Fundamentos de lógica e algoritmos, com exercícios em Java e Portugol.

![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white) ![IntelliJ IDEA](https://img.shields.io/badge/IntelliJ_IDEA-000000?logo=intellijidea&logoColor=white)

## Conteúdo

| Pasta | Descrição |
|---|---|
| `aulas/` | Exercícios das aulas 01 a 04 (projetos IntelliJ) e rascunhos |
| `atividades/tarefa-01, tarefa-02` | Tarefas em Java com capturas da execução |
| `atividades/complementar-01 … 06` | Fluxograma e Portugol (01), triângulos (03), basquete (04), exercícios (05) e cálculo de IMC (06) |

## Como executar

Abra a pasta de cada exercício no IntelliJ IDEA (ou compile com `javac Main.java && java Main`). Requer JDK 17+.

## Estrutura

```
.
├── aulas/
└── atividades/
```
